Friday

A personal AI assistant. Built by one person, used by one person.

Friday is a self-hosted assistant written in Python. It runs on a Raspberry Pi in its owner's home and uses Anthropic's Claude API for language understanding. It keeps its own memory in a local SQLite database and a set of markdown files on that machine.

This is not a commercial product. Friday is not offered for sale, distribution, or sign-up. There is no hosted service, no user accounts, and no way for anyone else to log in. It exists to assist its single owner.

What it does

  • Answers questions and holds context across conversations
  • Reads and manages its owner's Google Calendar
  • Drafts and sends email on its owner's behalf, when asked
  • Produces daily briefings from the above

Google account access

Friday asks its owner for permission to access their own Google Calendar and to send mail through their own Gmail account. That access is granted by the owner, to the owner's own data, and can be revoked at any time from Google Account permissions.
